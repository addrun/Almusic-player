## 0.1.4 多平台安装包发布 — 2026-10-14

0.1.2 的七个平台任务均完成打包，但应用资源检查发现依赖中的非运行资源，阻止了后续上传与发布。0.1.3 收紧打包范围并固定单任务架构，实际资源检查通过；Linux 文件名使用 x86_64 / amd64 / aarch64 名称，收集脚本的旧预期导致失败。0.1.4 修正资产名称校验，保留原隐私检查门槛。

干净源码目录使用官方 npm 锁文件安装依赖，Electron 生产构建与 11 组离线回归 151 项通过。新增发布资源校验 5 项、构建架构配置 9 项及锁定更新器的平台 / 架构选择 8 项通过；实际打包资源隐私夹具 27 项通过；任务栏套件使用模拟 Windows API，可在其他平台构建任务内运行，未调用真实账号或系统原生交互。

Windows x64 本地重新打包后扫描 4618 个文件，阻断项为 0；5 处泛化字面量提示已核对为库代码的公开参数或示例。精确保留有 SHA256 校验的第三方公共运行配置；删除不使用的依赖示例密钥、文档与 source map。PEM 检查覆盖真实正文和 JSON 转义形式，并区分导出标记；令牌检查避免在嵌入的 WASM Base64 中误报。

GitHub Actions 从同一标签分别构建 Windows x64 / ia32 / ARM64、macOS x64 / ARM64、Linux x64 / ARM64。只有七个任务都通过打包、ASAR 与额外资源隐私检查、安装包清单与来源提交校验后才汇总发布；更新文件的 SHA512、文件尺寸及安装包 SHA256 会再次校验。发布内容不含未打包目录、构建诊断、隐私报告或本机数据。实际构建状态和安装包文件见 [构建记录](https://github.com/mysterious-shhr/Almusic-player/actions/workflows/release.yml) 与 [Releases](https://github.com/mysterious-shhr/Almusic-player/releases)。

Windows / macOS 未签名，macOS 未公证；新增能力在其他平台的真实账号、播放及设备交互仍需实际使用验证。此前全量类型检查的既有诊断没有被此发布流程宣称为修复。
