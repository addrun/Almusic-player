# 隐私与本机数据说明

本文说明当前源码的数据处理方式，重点覆盖本分支新增的酷狗同步、收藏、选版和任务栏功能。音乐平台、社区服务、AI 服务及自定义音源各自的数据政策由服务提供方决定。

## 酷狗登录与同步

酷狗扫码登录使用官方 HTTPS 接口。登录、凭据和同步请求在 Electron 主进程中处理；账号相关 IPC 校验窗口、主框架来源和参数，页面获得所需的账号显示信息及歌单数据。

登录后，本机会保存登录令牌、酷狗用户编号、昵称、设备协议标识，以及云端歌单与曲目缓存。令牌用于向酷狗验证账号；不能将这些内容当作公开配置或调试信息。

新增的两个本机文件为：

| 文件                 | 内容                       | 保存方式               |
| -------------------- | -------------------------- | ---------------------- |
| `kugou-account.safe` | 登录凭据和账号显示信息     | Electron `safeStorage` |
| `kugou-library.safe` | 该账号的歌单目录及曲目缓存 | Electron `safeStorage` |

文件位于 Electron 的应用用户数据目录，而不是项目源码目录。在 Windows 上，`safeStorage` 使用操作系统提供的加密。安全存储不可用时不降级保存明文文件，只在本次运行的内存中使用账号与同步结果；Linux 的 `basic_text` 后端也不被接受。

软件显示名为 Almusic。为避免改名丢失已有状态，启动时优先已有 Almusic 用户数据目录，否则沿用已有 ZephyrusPlayer 目录；新安装使用 Almusic。更名不会复制账号文件到源码或公开仓库。

缓存按当前酷狗账号核验，避免把另一账号的缓存当作当前数据。加密保护不能替代对操作系统账号和本机访问权限的保护。

## 退出和仍保留的数据

在酷狗页面点击退出，会清理新增模块的登录状态和内存缓存，并删除上述两个 `.safe` 文件；这不会修改酷狗云端歌单。

以下数据属于独立本机偏好，退出酷狗后可能继续保留：

- 整张歌单的快捷收藏，按酷狗用户编号关联保存。
- 列表排序、密度及其他界面设置。
- 播放历史和本机跨平台单曲收藏。
- 用户主动选择的播放版本绑定。

这些偏好采用播放器现有配置或渲染进程本地存储，不能视为与酷狗凭据相同的系统加密数据。歌单快捷收藏的账号关联和歌曲标题也可能体现个人使用习惯。共享电脑时需分别检查收藏、历史和配置；卸载应用也未必删除全部用户数据。

## 单曲收藏与播放版本

本机跨平台单曲收藏保存必要的歌名、歌手、专辑、平台及歌曲标识，可能包含去掉查询参数的封面地址。清理函数排除账号数据、音频 URL 和临时播放签名。

“用于原歌单”按原酷狗曲目 hash 保存用户选中的平台歌曲标识与必要标题信息，不保存签名音频地址、账号数据或完整嵌套歌曲对象。它是本机偏好，不会写回酷狗云端。

上述限制只适用于新增收藏和选版快照；原播放器的队列、历史、音乐缓存及其他配置有各自的存储逻辑，不能据此断言整个应用从不保存播放地址。

## 网络请求

0.1.1 移除继承的页面百度统计脚本，页面启动不再加载这两段统计代码。页面字体仍可能从 Google Fonts 加载；音乐、社区及扩展功能的网络请求如下。

- 酷狗扫码、同步和原曲播放会向酷狗接口发送协议参数、设备标识，以及请求所需的账号凭据和歌曲标识。
- 自动播放回退和手动音源搜索会向网易云、GD 音乐台或用户配置的音源发送歌名、歌手、歌曲标识等查询信息。即使原曲未能播放，备用搜索仍可能产生请求。
- 播放时会连接返回的音频地址；封面和歌词会访问对应内容服务。
- 继承的社区功能会查询远程歌词、高潮和重点词数据；主动提交内容时还会发送相应曲目、标注、歌词及贡献者名称。
- 启用并使用 AI 歌词分析时，会向所选 AI 服务发送歌词、歌名、歌手及可能的专辑介绍。上游 AI 配置（包括自行填写的 API Key）保存在渲染进程本地存储，不能视为系统加密凭据。
- 更新检查、自定义 API、音源脚本和插件可能访问其配置的外部地址。使用者应检查所选服务及脚本。

外部服务通常也能获取发起请求的 IP 地址和必要请求头。本项目不能承诺第三方服务不会记录请求，也不能把“本机收藏”理解为整个播放器完全离线。

## 任务栏与远程控制

新增 Windows 任务栏歌曲信息卡只使用当前歌名、歌手及播放状态，在现有主进程中本地绘制，不读取账号文件或下载封面。任务栏上的信息可能被同一桌面前的其他人看到。

继承的局域网 HTTP 远程控制默认关闭。启用后可提供当前歌曲与播放控制；空白的允许 IP 列表会允许可访问服务的来源，因此应结合使用环境设置允许 IP 和系统防火墙。

## 提交反馈或公开源码

排查问题通常只需要操作步骤、歌曲名称、错误提示及脱敏后的统计结果。提交 issue、日志或截图前，请去掉：

- 密码、Cookie、令牌、API Key、登录二维码及二维码会话标识。
- 账号编号、昵称、头像、私人歌单地址与其他人的信息。
- 用户数据文件、浏览器本地存储、完整接口响应和带签名参数的播放地址。
- 个人文件路径、系统用户名、播放历史和无关窗口内容。

不要直接上传应用用户数据目录、安装备份或原始调试日志。即使文件经过加密，也不应把真实账号文件放进公开仓库。源码示例和自动测试应使用明确的虚构夹具。
